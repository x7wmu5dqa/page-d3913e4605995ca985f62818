特洛伊(BAACLOUD)

在混杂冗余的国际流量交换中，数据通路并不缺少物理光缆，而是缺少兼顾规则自洽与路由收敛的调度方案。
本文档记录特洛伊(Baacloud)现行网络资源配比、分流订阅格式规范及设备挂载指引，供工程技术团队与深度使用者随时调取。

分流架构的系统论述

01 / DISCOURSE

长期以来，跨界域传输面临的瓶颈并不单纯是物理距离带来的延迟，而是拓扑结构在突发访问时的拥塞扩散。特洛伊(Baacloud)在节点部署层面采取了多核分流理念，将高负载任务与低频日常报文在接入边缘实施解耦。

“所谓高可用网络，绝非无限堆砌无序冗余，而是将协议开销与路径选择权精确返还给终端。”

通过构建规整的分组匹配规则，订阅客户端无需依赖全量广播或盲目重试，即可根据数据特征自动命中适宜的通道。这种设计规避了传统中继模式下因个别出口震荡引发的整网降级问题。

边缘解析与路由分派

针对常见流媒体协议与开发工具链，特洛伊(Baacloud)采用分层配置模版。终端在拉取配置后，本地核心引擎可直接执行基于地理位置或域名后缀的二叉匹配，削减了往返握手周期的耗时。

端点冗余机制

当某组中继服务器出现网络丢包上浮时，健康检查系统会实时调整订阅元数据中的备用优先级序列，确保业务端连接在无感知状态下平滑迁移到热备链路。

多端同步与核心支持

03 / INTEGRATION

桌面开发环境

兼容主流开源分流内核。支持在 macOS 与 Windows 系统通过 Clash、v2rayN 或通用配置链接导入节点集合，实现本地系统代理与 TUN 模式的按需分流。

移动设备挂载

iOS 平台推荐使用 Shadowrocket、Loon 或 Quantumult X 读取订阅；Android 平台可借助 Clash Verge 或 Sing-box 完成配置下发，保障后台省电常驻。

网关与路由级部署

针对具备 OpenWrt 或软路由固件的局域网环境，支持下发纯文本 yaml 节点清单与自定义白名单规则，赋予全屋智能终端透明代理接入体验。

常见疑难与技术备忘

04 / INQUIRIES
  1. 01

    如何获取并在终端载入特洛伊(Baacloud)订阅？

    在用户控制台获取专属订阅链接后，复制 URL 并粘贴至适配的客户端订阅管理器内。执行初次更新时，客户端将自动抓取全部可用中继节点池及内建规则模板。

  2. 02

    不同套餐的设备在线限制如何计算？

    设备数指的是在同一时间向接入集群发起通信请求的独立终端 IP 或标识数量。以基础版为例，允许 3 台不同设备同时建立隧道，多出配额的设备将受到握手阻断。

  3. 03

    当节点发生连通性超时，应采取何种排查顺序？

    首先建议在客户端内重新触发一次“更新订阅”，确认本地节点列表为最新有效版本；其次检查本地设备系统时间是否精确同步到秒级标准时间；最后切换至其他可用节点并检测 DNS 分流配置。

  4. 04

    流量配额的重置周期是固定的吗？

    所有阶梯方案的流量配额严格以账单起始日为自然月周期循环重置。未消耗完毕的流量不会跨周期结转，用量超出限制后节点端口将自动挂起直至进入下一账单日或增购配额。
